📸 Lunova Photography

Lunova Photography is a responsive photography website built with HTML, CSS, and JavaScript. It features a clean layout, visual content, and interactive elements designed to provide a smooth browsing experience.

✨ Features

* Responsive photography website layout
* Interactive navigation and menu options
* JavaScript-powered website interactions
* Photography images and visual presentation
* Organized styling using CSS
* External font integration for improved typography

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Font Awesome

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open the main HTML file in your browser.
4. Explore the website and its interactive features.

🎯 Project Goal

The goal of Lunova Photography is to create an attractive photography website while practising frontend development, responsive styling, and JavaScript functionality.
